# go-playground

A personal playground for learning Go. Every concept I pick up gets rewritten here as
small, runnable code with tests, so I can come back and run it instead of re-reading
the theory.

## About

The material follows [Go Advanced](https://zalopay-oss.github.io/go-advanced/) by
ZaloPay OSS. The notes and examples are my own take on it, written while working
through the book.

This is a learning repository, not a library meant for production use.
